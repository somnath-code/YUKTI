# Changelog

## 1.1.0

- Adopted the repository layout for apps, adapters, workers, Airflow, database, templates, configuration, operational guidance and verification.
- Split daily news and research collection, quality validation, weekly editorial preparation and the weekly SUTRA draft into five DAGs.

- Split the SUTRA template into reusable layouts and styles. Added optional print corrections, a locked uv environment and separate CI workflows.
- This release package is for local and private use. The hosted sample portal uses its existing private deployment.
