# Contributing

Use Python 3.12, make a focused branch and run `python -m pytest -q`. Test PostgreSQL for query or migration changes. Avoid adding new editorial or source-policy exceptions without an example and a clear owner. Update operator steps when configuration changes. Never commit tokens, .env contents, internal source snapshots or production credentials. Open a pull request using the provided template.
